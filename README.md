## ✨ About VYRA

**VYRA** is a modern coffee house website concept created to bring the atmosphere of a premium café to the digital world.

Built with a focus on aesthetics, usability, and responsive design, the experience combines rich coffee-inspired visuals with refined layouts and fluid interactions.

From the first impression to the smallest interface detail, VYRA is designed to make every scroll feel intentional.

## 🎨 Highlights

- ☕ **Premium Café Aesthetic** — Warm visuals, elegant typography, and a carefully crafted layout.
- 📱 **Fully Responsive** — Adapted for mobile phones, tablets, laptops, and desktop screens.
- ✨ **Smooth Animations** — Fluid transitions and motion effects for a more engaging experience.
- 🖼️ **Immersive Visuals** — Coffee-inspired imagery that brings the brand to life.
- 🧭 **Intuitive Navigation** — A clean interface designed for a comfortable browsing experience.
- ⚡ **Modern Frontend** — Built using React and Vite for a modern development workflow.

## 🚀 Getting Started

Want to run VYRA locally? Follow these steps.

### Prerequisites

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Saumya-Mishraa/vyra-coffee-house.git
```

**2. Navigate to the project folder**

```bash
cd vyra-coffee-house
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Build for production**

```bash
npm run build
```
